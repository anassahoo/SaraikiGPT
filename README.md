# SaraikiGPT

SaraikiGPT is a decoder-only Transformer language model that will be trained from scratch for Saraiki text generation.

The main goal of this project is to understand how GPT-style language models work by building the complete pipeline from the beginning instead of fine-tuning an existing model.

## Planned Pipeline

Saraiki Dataset  
→ Text Cleaning and Normalization  
→ Tokenizer  
→ Dataset Loader  
→ Causal Self-Attention  
→ Transformer Blocks  
→ GPT Architecture  
→ Training  
→ Text Generation  
→ Evaluation

## Project Goal

Build a compact Saraiki language model that can generate Saraiki text from a given prompt.
